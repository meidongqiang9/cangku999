# 云端点餐小程序 - 商家配置指南

## 商家设置流程

### 第一步：配置商户信息
1. 进入小程序 → 点击「我的」
2. 填写店铺名称
3. 填写微信支付商户号和密钥
4. 点击「保存设置」

### 第二步：生成店铺二维码
1. 在「我的」页面点击「生成二维码」
2. 复制生成的链接
3. 使用二维码生成工具生成二维码图片
4. 打印二维码贴在餐桌或门口

### 第三步：部署云函数
1. 在微信开发者工具中右键 `cloudfunctions/payment`
2. 选择「上传并部署：云端安装依赖」
3. 确保已开通微信云开发

## 支付流程

```
消费者扫码 → 进入对应餐厅小程序
    ↓
输入桌号、人数 → 点餐
    ↓
点击「走菜」→ 提交订单
    ↓
用餐结束 → 点击「结账」
    ↓
调用微信支付 → 钱直接进入餐厅商户账户
```

## 云函数 payment 配置说明

云函数 `cloudfunctions/payment` 负责：
1. 生成商户订单号
2. 调用微信支付统一下单接口
3. 返回调起支付所需的签名参数

### 需要配置的参数
- `mchId`: 微信支付商户号
- `mchKey`: 微信支付商户密钥
- `subAppId`: 子商户AppID（可选）

### 配置位置
餐厅老板在「我的」页面设置后，数据保存到 `wx.getStorageSync('shopConfig')`

## 注意事项

1. **商户号配置**：必须在微信商户平台正确配置API密钥
2. **AppID对应**：小程序AppID必须与商户号关联
3. **结算账户**：资金自动结算到商户号绑定的银行账户
4. **开发测试**：未配置商户号时为模拟支付模式
